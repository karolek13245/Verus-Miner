## ✨ Features

- 🎨 **Beautiful Hacker-Style UI** with Verus Coin logo
- ⛏️ **Full Mining Control** - Start, Stop, Restart, View Output
- ⚙️ **Easy Configuration** - Edit settings with nano editor
- 📊 **Live Monitoring** - View mining hashrate in real-time
- 🔄 **Auto-Restart** - Automatically restart on failure
- 📱 **Optimized for ARM64** - Built specifically for Android
- 🔋 **Battery Friendly** - Customizable thread usage
- 🚀 **One-Click Install** - Automated setup script
- 📁 **Organized Structure** - Scripts, configs, and docs in separate folders

## 📱 Requirements

| Requirement | Details |
|-------------|---------|
| **Device** | Android with 64-bit ARM processor (ARMv8) |
| **Storage** | 500MB+ free space |
| **RAM** | 2GB+ recommended |
| **Android** | 7.0 or higher |
| **Internet** | Stable Wi-Fi connection |
| **Termux** | Latest version from F-Droid |
